\section{Introduction}
\label{sec:intro}

Knowing the exact 6D pose of an object --- its 3D translation $\bt \in \R^3$ and rotation $\bR \in \SO$ --- is essential for tasks like robotic manipulation in real-world settings. While 2D object detection has improved enormously thanks to CNNs, going from 2D detections to full 3D poses is still hard, mainly because the camera projection loses depth information.

The official LineMod protocol~\cite{hinterstoisser2012model} makes this especially challenging: only $\sim$15\% of the real frames per object are available for training, while the other 85\% are reserved for testing. Current top methods handle this data scarcity either by generating large amounts of synthetic training images per object~\cite{he2020pvn3d, he2021ffb6d}, or by designing architectures that tie predictions directly to observed 3D points through dense per-pixel fusion~\cite{wang2019densefusion}. In this work we explore a third, much cheaper approach: we keep a lightweight global-fusion architecture trained on real data only, and change just the way we \emph{formulate} the regression target.

Our pipeline has three stages:

\begin{enumerate}
    \item \textbf{2D Object Detection.} We use a fine-tuned YOLO11n~\cite{ultralytics2024yolo11} to detect objects and extract bounding boxes, evaluated with the strict mAP@50-95 metric.

    \item \textbf{RGB-only Baseline.} We train a ResNet-50 backbone with two regression heads (one for the rotation quaternion, one for the translation vector) to show the limits of estimating depth from RGB alone.

    \item \textbf{RGB-D Global Fusion with anchored regression.} We build a lightweight architecture that concatenates globally pooled RGB, depth, and camera-metadata features. Instead of predicting the absolute position directly, the translation head predicts a residual offset relative to a 3D \emph{anchor} that we compute by back-projecting depth values from inside the detected bounding box. Rotations use the 6D continuous representation from Zhou~\etal~\cite{zhou2019continuity}.
\end{enumerate}

We test everything on the official LineMod split, training on 2{,}016 real images and testing on 13{,}407, with no synthetic data. Our main contributions are:

\begin{itemize}
    \item An \textbf{anchored residual formulation} for the translation target in global RGB-D fusion: with the same architecture, data, and training recipe, it raises ADD(-S) accuracy from 6.8\% (direct absolute regression) to 95.1\% in a full end-to-end evaluation with predicted detections.
    \item A controlled \textbf{ablation comparing different geometry input formats} (raw metric depth, anchor-normalized depth, per-pixel XYZ maps), showing that anchoring the target --- not a richer input encoding --- is what makes the difference.
    \item A \textbf{memorization analysis}: retrieval- and oracle-nearest-neighbor baselines cap any pose-copying strategy at 7.1\% on this protocol, and accuracy stays stable up to $12^\circ$ of viewpoint gap, ruling out the possibility that the model is just memorizing training views.
    \item The system outperforms the per-pixel variant of DenseFusion (86.2\%)~\cite{wang2019densefusion} under the same protocol and data regime, while using only $\sim$36M parameters, with no per-point processing and no refinement stage.
\end{itemize}
