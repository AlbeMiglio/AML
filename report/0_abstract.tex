\begin{abstract}
Estimating the full 6D pose (3D position and 3D orientation) of objects from images is important for applications like robotic grasping and augmented reality. We build a modular pipeline that tackles this problem on the LineMod benchmark, following the standard protocol where only $\sim$15\% of real frames are used for training, with no synthetic data. Our key finding is that the main reason lightweight fusion models fail on this task is how the translation target is set up: asking the network to directly predict an absolute 3D position from global features gives just 6.8\% ADD(-S), no matter which input modalities are combined. To fix this, we anchor the prediction to the observed geometry: we back-project a 3D anchor point from the depth map inside the detected bounding box and let the network predict only the small residual offset from this anchor to the true object center. Without changing the model, the data, or the training setup, this anchored approach reaches 95.1\% ADD(-S) in a full end-to-end evaluation using predicted detections. This beats the per-pixel version of DenseFusion (86.2\%) under the same conditions, without needing dense per-point fusion, iterative refinement, or synthetic training images. A memorization analysis confirms that the model generalizes across viewpoints rather than copying poses from similar training frames. Our code is publicly available at \url{https://github.com/AlbeMiglio/AML}.
\end{abstract}
