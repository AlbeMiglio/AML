\begin{abstract}
6D object pose estimation is a central problem in computer vision, with applications in robotic manipulation and augmented reality. We present a modular, phase-oriented pipeline for estimating the 3D translation and rotation of objects on the LineMod benchmark under its standard protocol, where only $\sim$15\% of the real frames are available for training and no synthetic data is used. We show that in this regime the dominant failure mode of lightweight fusion architectures is the \emph{formulation} of the translation target: directly regressing an absolute 3D position from globally pooled features fails (6.8\% ADD(-S)), regardless of the modalities fused. We therefore anchor the regression to the observed geometry. A 3D anchor point is back-projected from the depth inside the detected bounding box, and the network predicts only the residual offset between this anchor and the object center. With the model, data, and training recipe unchanged, this anchored formulation reaches 95.1\% ADD(-S) in a fully end-to-end evaluation with predicted detections. This is above the per-pixel variant of DenseFusion (86.2\%) under the same protocol, without dense per-point fusion, iterative refinement, or synthetic training images. A memorization analysis (retrieval and oracle nearest-neighbor bounds, plus accuracy as a function of viewpoint novelty) indicates that this result reflects actual viewpoint generalization rather than memorization of nearby training views. Our code is publicly available at \url{https://github.com/AlbeMiglio/AML}.
\end{abstract}
